# gap:Historical data acquisition and dataset construction for backtesting and model training (Polymarket + Pump.fun)

## Summary
POLYMARKET: There is no official deep-granularity historical archive, and the April 28, 2026 CLOB V2 cutover made this worse. Officially, the CLOB API's /prices-history endpoint (interval 1m/1h/6h/1d/1w/max + fidelity in minutes, ~300 req/min, no auth) serves mid-price series, but for resolved/closed markets it only returns data at coarse (~12h+) fidelity — a confirmed limitation (Polymarket/py-clob-client issue #216) that makes official data unusable for realistic fill simulation on past markets. The Data API (data-api.polymarket.com/trades, pagination clamped ~10000 offset) and Gamma API (resolved-market metadata/outcomes) remain the metadata backbone. The V2 migration wiped open orderbooks, moved to new ctf-exchange-v2 contracts and pUSD, broke all V1 SDK integrations, and Polymarket stopped supporting its old Goldsky subgraph — the community workaround (warproxxx/poly_data) is to backfill OrderFilled events straight from the V2 contract (0xE111...996B) on Polygon via Envio HyperSync (free tier: hours-to-days for full backfill; V1-era pipeline preserved at a `v1-final` git tag). Dune's curated polymarket_polygon tables (market_trades per-fill, market_details, market_prices_hourly; ~24h lag; resolved-market history going back ~4 years, unified with Kalshi since May 2026) are the cheapest cross-V1/V2 trade+candle source. Real L2 orderbook depth history exists ONLY from third-party recorders that started capturing in late 2025/early 2026: DepthFeed (event-driven full-ladder books since Jan 2026, 450M+ books, $29–$249/mo), PolymarketData.co (L2 depth + minute prices "from Aug 2025", 19B+ rows, S3 parquet dumps), PMData.dev (tick-level books for the 7 crypto up/down series since Feb 2026, parquet-over-HTTP), PolyBackTest (1-min depth). The IMDEA 86M-bet arbitrage study (arXiv 2508.03474 / AFT 2025) did NOT publish its dataset. Community bots that actually run (guberm/polymarket-bot, poly-maker) overwhelmingly use the record-your-own-journals pattern: log estimates/trades/books live, then replay deterministically offline.

PUMP.FUN / SOLANA: Launch-level history is well covered and cheap. Dune has pumpdotfun_solana decoded tables (e.g. pump_call_create for every token creation) plus dashboards tracking creates/graduations; Bitquery serves Pump.fun+PumpSwap trades, OHLCV, bonding-curve progress and graduations via GraphQL — real-time "Trading" cube covers ~last 30 days MEV-filtered, with `dataset: combined` archive queries for older per-instruction history ($49–$299/mo self-serve). Helius covers full-chain archival: getTransactionsForAddress queries any address's entire history since genesis (100 credits/request; plans $0/1M, $49/10M, $499/100M credits), practical for per-token backfills but a whole-program backfill of billions of Pump.fun transactions would cost thousands of dollars in credits — for bulk backfill the free route is Triton's Old Faithful archive (entire Solana ledger as one CAR file per epoch on files.old-faithful.net CDN, Solana-Foundation-sponsored public good). The Google BigQuery public dataset (crypto_solana_mainnet_us) stopped updating March 31, 2025 and carries severe query-cost risk ($90 per 3.58TB scanned; $5k single-query horror stories). For forward recording, LaserStream gRPC (Yellowstone-compatible, ~24h/216k-slot replay on disconnect, mainnet requires Helius Business $499/mo, TB add-ons $400/5TB+) or Shyft's unmetered Yellowstone gRPC from $199/mo with slot replay are the main options; a filtered Pump.fun-program stream compressed to parquet is on the order of tens of GB/month (my estimate — storage cost negligible next to the stream subscription). Labeled datasets now exist: RED-PUMP-2026-v1 on Zenodo (CC-BY-4.0, 860,213 launches May 8–Jun 10 2026 with survival outcomes, socials, initial mcap; 0.198% graduation), MELT (github.com/git-disl/MELT; 41,470 migrated Pump.fun launches Dec 2024–Mar 2025, 122 features incl. Jito-bundle coordination traces, >1TB raw; CC BY-NC — non-commercial license is a problem for a profit bot), and "From Hype to Collapse" (arXiv 2603.24625; 76,469 rug-pull candidates H1-2025 but deliberately excludes most Pump.fun non-graduates). RugCheck exposes a public REST API (api.rugcheck.xyz, X-API-KEY) for current risk verdicts, but no one serves historical point-in-time verdicts — you must snapshot them yourself.

RECOMMENDED MINIMAL PIPELINES. Polymarket bot: (1) backfill all resolved-market metadata + outcomes from Gamma, per-fill trade tape from Dune polymarket_polygon.market_trades (free tier) or self-run HyperSync OrderFilled backfill for both V1 and V2 contract eras; (2) buy one month of DepthFeed Quant ($29) to calibrate a slippage/queue model against real ladders instead of mid-quotes; (3) from day 1, record your own CLOB WebSocket book+trade firehose for the markets you care about (this is what every serious community bot does) and treat 2026-04-28 as a hard regime boundary. Pump.fun bot: (1) train launch/graduation priors on RED-PUMP (free, licensed for reuse) + Dune creates/graduations tables, using MELT only for research insight, not commercial model training; (2) per-token forensic backfills via Helius gTFA on the $49 plan; (3) day-1 forward recording of the Pump.fun + PumpSwap program streams via Shyft gRPC ($199/mo) or Bitquery streams ($49–79/mo) into parquet — because fee/incentive regimes shift every few months, your own recent recording is worth more than any deep backfill. Total minimal budget: roughly $30–80/mo (Polymarket side) + $50–200/mo (Solana side), versus $500–1000+/mo for the Helius-Business/LaserStream-TB route.

## Key findings
- Polymarket /prices-history (CLOB API): params interval (1m,1h,6h,1d,1w,max) + fidelity (minutes) + startTs/endTs; ~300 req/min, no auth — but for RESOLVED markets it returns empty below ~12h fidelity (fidelity:60 -> {'history':[]}, fidelity:720 -> data), confirmed in Polymarket/py-clob-client issue #216 (opened 2025-12-22, no team response). Official API alone cannot support fine-grained backtests of past markets.
- Polymarket Data API (data-api.polymarket.com): GET /trades (by user or market, page size clamped to 10000, offset cap rejects deep pagination with 400), /positions, /activity (TRADE/SPLIT/MERGE/REDEEM), /holders. Good for wallet-level tapes, not for full-market history at depth.
- V2 cutover (2026-04-28 ~11:00 UTC): new ctf-exchange-v2 contracts, rewritten CLOB, USDC.e->pUSD collateral, ~1h downtime, ALL open orders wiped, no V1 SDK backward compatibility; Polymarket also stopped supporting the old Goldsky subgraph indexer — pre/post series must be stitched from two different contract event streams.
- Community-standard V2 backfill: warproxxx/poly_data streams OrderFilled events from V2 contract 0xE111180000d2663C0091e4f400237545B87B996B via Envio HyperSync (no RPC throttling; free tier needs envio.dev bearer token, full backfill 'several hours to a few days', resumable; paid tier unthrottled), joins CLOB /markets (1000/page) + Gamma metadata into markets.csv/orderFilled.csv/trades.csv covering ~1.5M markets. V1-era pipeline preserved at git tag v1-final.
- Dune curated tables (free tier usable, 1,000 credits/mo): polymarket_polygon.market_trades (per-fill, taker/maker), market_details, market_prices_hourly, users_address_lookup; positions/ohlcv_hourly/market_actions are Enterprise-gated; ~24h update lag; May 2026 Dune unified Polymarket+Kalshi with ~4 years of resolved-market history. Kalshi per-fill data is Enterprise-gated (public tier = daily aggregates only).
- L2 orderbook depth history exists ONLY via third-party recorders, all starting late-2025/2026: DepthFeed (polymarketbacktesting.com) — event-driven FULL bid/ask ladders since Jan 2026, 450M+ books, 380K+ markets (crypto up/down series: BTC/ETH/SOL/XRP/DOGE/BNB/HYPE at 5m–24h windows), REST+JSON, tiers Free/$29/$99/$249/mo by lookback (7d/30d/90d/full); PolymarketData.co — L2 depth + minute prices claimed 'from Aug 2025', 1M+ markets, 19B+ rows, REST/Python SDK/S3 parquet-CSV-JSON dumps; PMData.dev — tick-by-tick books+trades for 7 up/down coins since Feb 2026, parquet per-slug over HTTP; PolyBackTest — claims 1-minute full-depth history (site blocked fetch, unverified).
- IMDEA 'Unravelling the Probabilistic Forest' (arXiv 2508.03474, AFT 2025): $40M arbitrage across 86M bets/7,000+ markets Apr 2024–Apr 2025, built from on-chain order data via py-clob-client — NO public dataset/artifact release found on the DROPS page or arXiv.
- How real Polymarket bots got data: guberm/polymarket-bot records its own trades.jsonl + estimates.jsonl journals live and replays them deterministically offline (Brier/calibration scripts), using Data API only for resolution checks; djienne/Polymarket-bot is live-only with trade-history persistence for Kelly calibration; warproxxx/poly-maker has captured journals but 'a replay backtester over the captured journals is not yet built'. Record-your-own-data is the de facto community pattern.
- Pump.fun on Dune: decoded pumpdotfun_solana schema (e.g. pump_call_create = complete token-creation history) plus community dashboards for graduations/trades (dune.com/jondar/pumpfun, dune.com/atmday/pumpfun-pumpswap). Cheapest launch-level source; free tier 1,000 credits/mo, paid ~$75+/mo (credits billed even for failed queries).
- Bitquery Pump.fun/PumpSwap APIs: GraphQL + WebSocket; 'Trading' cube = MEV-filtered swaps with USD price/mcap/supply for ~last 30 days; older history via dataset:combined archive (bonding-curve internals, per-instruction detail; Trade_Side unavailable in aggregate archive queries); OHLCV down to 1s intervals; token creations via TokenSupplyUpdates filtered on program 6EF8rrecthR5Dkzon8Nwu78hRvfCKubJ14M5uBEwF6P; graduations via dedicated Pump.fun->PumpSwap migration queries. Plans ~$49–$299/mo self-serve (points-based; $50/1M extra points; streaming billed per stream-minute and GB).
- Helius archival: getTransactionsForAddress covers entire Solana history since genesis (2.3T rows indexed, 2–10x faster archival backend), 100 credits/request (up to 100 full txs or 1,000 signatures), Developer plan+; plans Free $0/1M credits/10rps, Developer $49/10M/50rps, Business $499/100M/200rps, Professional $999/200M/500rps. Fine for per-token backfills (a memecoin has 10^2–10^4 txs); whole-program Pump.fun backfill (billions of txs) would run to thousands of dollars in credits — my arithmetic estimate from verified prices.
- LaserStream gRPC (Helius): Yellowstone-wire-compatible, multi-region failover, historical replay limited to ~216,000 slots (~24h) — good for gap-healing a self-recorder, useless as an archive; mainnet gRPC requires Business ($499/mo)+; TB add-ons $400/5TB, $750/10TB up to $6,000/100TB (Professional). Cheaper unmetered alternative: Shyft Yellowstone gRPC from $199/mo, no credit/bandwidth metering, slot replay, 7 regions.
- Free bulk Solana backfill: Triton One 'Old Faithful' (Project Yellowstone, Solana Foundation sponsored) — the ENTIRE Solana ledger from genesis packed as one CAR file per epoch, served free from CDN at files.old-faithful.net (also on Filecoin/S3), queryable via JSON-RPC/gRPC or self-hosted; this is the sane route for a full Pump.fun-program historical replay without vendor credit costs.
- Google BigQuery crypto_solana_mainnet_us: public community dataset (blocks/transactions/instructions) but transactions table STOPPED UPDATING 2025-03-31 per Google Cloud community forum; pay-per-scan pricing is dangerous at Solana scale ($90 for a 3.58TB scan; reports of $5k single-query bills).
- Labeled graduation dataset (free, commercial-friendly): RED-PUMP-2026-v1, Zenodo DOI 10.5281/zenodo.20633486, CC-BY-4.0 — 860,213 pump.fun launches (May 8–Jun 10, 2026), 832,941 terminal outcomes, 1,651 graduations (0.198% pooled rate, down 3.18x from 0.63% in Sep–Oct 2025); fields: mint, timestamps, initial mcap SOL, Twitter/website/Telegram flags, description length; findings: Telegram presence lifts graduation 8.94x (1.485% vs 0.166%), all-3-socials 17.4x, initial mcap >30 SOL (creator self-buy proxy) hazard ratio 4.51. Paper: arXiv 2607.02823.
- Labeled rug/manipulation dataset (research-only license): MELT (github.com/git-disl/MELT, arXiv 2602.13480) — 41,470 Pump.fun launches that migrated to DEX, Dec 1 2024–Mar 1 2025, 200M+ parsed txs (>1TB raw, Google Drive zips), 122 features incl. Jito-bundle coordination (36.5% of supply held by coordinated accounts), risk labels 84.13% high / 11.34% medium / 4.53% low — license CC BY-NC-SA 4.0, i.e. NOT licensed for commercial bot training.
- 'From Hype to Collapse' (arXiv 2603.24625): 100,063 tokens on Orca/Raydium/Meteora H1-2025, 76,469 rug-pull candidates, 0.26% false-positive rate on 382-token manual audit; built from official Solana RPC + Solscan API; explicitly EXCLUDES most Pump.fun tokens (only ones that created LPs) — poor fit for bonding-curve-stage models; paper says dataset released but no link found on the HTML page (uncertain availability).
- Regime breakpoints that must partition any Pump.fun backtest: graduation target moved Raydium->PumpSwap (Mar 2025); 'Project Ascend' dynamic fees (Sep 2025); BOOST (late July 2026) redirected ~20% of migration liquidity into automatic first-5-minute post-migration buys with burns — graduation rate jumped from ~0.8% (June 2026 avg) to 2.5% (prior week) to 4.7% (4-day avg) peaking at 6.7% on one Friday (The Block, 2026-07-29). Pre-BOOST training data materially understates current graduation odds.
- Fraud contamination baselines: Solidus Labs (May 2025) analyzed 7M+ Pump.fun tokens Jan 2024–Mar 2025: 98.6% showed pump-and-dump/rug characteristics, <100k kept liquidity >$1,000; 93% of 388k Raydium pools showed soft-rug patterns (median loss $2,832). Any volume/holder feature from this ecosystem is heavily wash-trade/bundle contaminated.
- RugCheck: public REST API at api.rugcheck.xyz (Swagger docs, X-API-KEY header, free key) with 20+ on-chain risk signals; SolSniffer API returns Snif score/risks per token. NEITHER offers historical point-in-time verdicts as a product — snapshot verdicts yourself at detection time to avoid label leakage; one Gumroad micro-dataset (140+ low-cap charts with RugCheck data) exists but is tiny.
- Cost bottom line — Polymarket: $0 (Gamma+Dune free tier+HyperSync free backfill) to $29–249/mo (DepthFeed book archive). Solana: record-your-own filtered firehose = $199/mo Shyft unmetered gRPC (or $49–79/mo Bitquery streams) + <$5/mo object storage for tens of GB parquet (volume is my estimate); vendor backfill = Bitquery archive $49–299/mo or Helius $49–499/mo in credits; free deep backfill = Old Faithful CAR files (compute/egress only).

## Pitfalls
- Mid-quote backtests on Polymarket are structurally overstated AND the official API cannot fix it: /prices-history collapses to ~12h granularity on resolved markets, so realistic fill simulation requires third-party L2 archives (none older than Aug 2025 at best, most Jan–Feb 2026) or your own recording. There is effectively NO L2 depth history for the 2024 election cycle.
- V2 discontinuity (2026-04-28): different contracts, different OrderFilled event schema, different fee model, orderbooks cleared, pUSD collateral. Treat pre/post-cutover as separate regimes; stitch trade tapes from V1 and V2 contract addresses separately (poly_data v1-final tag vs main). Liquidity right after cutover was artificially shaped by a $1M rewards program — exclude or flag late-April/May 2026.
- Polymarket's old Goldsky subgraph is deprecated/no longer complete — pipelines and tutorials written before mid-2026 that rely on it silently return partial data.
- Data API pagination caps (~10000 offset clamp, 400 on deep pages) make it unsuitable for full-market trade backfills; use Dune or on-chain event backfill instead.
- Pump.fun regime breakpoints MUST partition backtests: Raydium->PumpSwap graduation (Mar 2025), Project Ascend dynamic fees (Sep 2025), BOOST (late Jul 2026). Graduation base rate moved 0.63% (Sep–Oct 2025) -> 0.198% (May–Jun 2026) -> ~4.7% avg/6.7% peak (post-BOOST) — a >30x swing; any classifier trained on one regime is miscalibrated in the next.
- Survivorship bias in labeled memecoin datasets: MELT includes only launches that migrated to DEX (~1% of launches); 'From Hype to Collapse' excludes most Pump.fun tokens entirely. Training on these overweights survivors; RED-PUMP is the only found dataset covering the full launch population including the 99.8% that die.
- Wash-trading/bundling contamination: Solidus Labs found 98.6% of Pump.fun tokens with pump-and-dump/rug signatures; MELT measured 36.5% of token supply held by coordinated bundled wallets. Raw volume, holder-count and buy-pressure features are adversarially manipulated — prefer Bitquery MEV-filtered trade cubes or engineer bundle/coordination features (Jito bundle IDs) rather than trusting notional volume.
- License trap: MELT is CC BY-NC-SA 4.0 — using it to train models for a personal PROFIT-seeking bot is arguably commercial use; RED-PUMP (CC-BY-4.0) is safe. Check licenses before ingesting academic corpora.
- BigQuery Solana public dataset is stale (no updates since 2025-03-31) and unbounded scans can bill thousands of dollars; always dry-run with maximum_bytes_billed set. Dune bills credits even for FAILED query executions.
- LaserStream replay is ~24h only — it heals stream gaps but is not a backfill; if you don't record from day 1 the data is gone (or costs vendor money). Both bots should ship the recorder before the strategy.
- RugCheck/SolSniffer verdicts are current-state: fetching today's verdict for a 2025 token leaks post-hoc information into training labels. Snapshot risk verdicts at detection time in your own pipeline.
- Whole-program historical backfill of Pump.fun via per-request APIs (getSignaturesForAddress/gTFA) costs thousands of dollars in credits at billions of transactions — use Old Faithful CAR files or buy the launch-level aggregates (Dune/Bitquery) instead; per-token backfills are cheap.
- Uncertain items: PolyBackTest details (403 on fetch); Kaggle tick-level dataset contents; PolymarketData.co 'from Aug 2025' coverage claim and pricing; whether Gamma/CLOB still serve V1-era market metadata indefinitely post-V2 (poly_data still pulled ~1.5M markets in mid-2026, suggesting yes, but no official retention statement found); 'From Hype to Collapse' dataset link; Flipside's current Solana offering (search budget exhausted before verification — treat as unverified).
